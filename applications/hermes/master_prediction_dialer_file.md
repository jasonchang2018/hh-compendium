# master_prediction_dialer_file

Source: [master_prediction_dialer_file.sql](../../src/sql/master_prediction_dialer_file.sql)

Allocates dialer contacts and builds the ranked calling dataset.

| Object | Name |
| --- | --- |
| Table | `edwprodhh.hermes.master_prediction_dialer_file` |
| Stored procedure | `edwprodhh.hermes.calculate_master_prediction_dialer_file()` |
| Task | `edwprodhh.hermes.replace_master_prediction_dialer_file` |

The task uses `hermes_wh` and runs after all of these declared predecessors:

- `edwprodhh.hermes.replace_master_prediction_proposal`
- `edwprodhh.hermes.replace_master_prediction_phone_selection_dialer`

It calls the stored procedure.

**Inputs:** `edwprodhh.hermes.master_config_constraints_global_weightsdow`, `edwprodhh.hermes.master_config_constraints_global`, `edwprodhh.hermes.master_prediction_scores`, `edwprodhh.pub_jchang.master_debtor`, `edwprodhh.hermes.master_prediction_pool`, `edwprodhh.hermes.master_prediction_proposal_log`, `edwprodhh.hermes.master_prediction_proposal`, `edwprodhh.hermes.master_config_objectives`, `edwprodhh.hermes.master_config_channel_costs`, `edwprodhh.hermes.master_prediction_phone_selection_dialer`, `edwprodhh.hermes.transform_config_artificialgroup_associations`, `edwprodhh.hermes.master_config_artificialgroup`, `edwprodhh.hermes.master_config_plgroup`, `edwprodhh.hermes.master_config_dialer_lists`, `edwprodhh.pub_jchang.dimzip`.

**Logic:**

1. Unpivots agent and agentless scores, maps debtors to dialer departments, and considers recent/current digital-contact proposals when filtering conflicts.
2. Attaches the selected dialer phone and computes profit/margin ranks with configured objective weights. Dialer margin is `profit / fee`, unlike the ordinary proposal's `profit / cost`.
3. Allocates agent calls first, then agentless calls while excluding already selected packets. Applies global/group call constraints and configured dialer list sizes.
4. Adds upload date, selected phone, source field, packet member, and calling priority. Keeps proposal flags and ranking metrics for audit; request IDs are generated by its log procedure.

The procedure rebuilds its output table with `CREATE OR REPLACE TABLE ... AS SELECT`.

## Output columns

`edwprodhh.hermes.master_prediction_dialer_file`:

| Column | Meaning |
| --- | --- |
| `debtor_idx` | Unique debtor/account identifier. |
| `client_idx` | Unique client identifier used to join configuration and client data. |
| `pl_group` | Placement group associated with the account or configuration rule. |
| `hermes_group` | Group used for allocation; a placement/artificial group for ordinary proposals or a dialer department for calls. |
| `proposed_channel` | Contact channel associated with a candidate, recommendation, or requirement. |
| `is_priority_minimum` | Whether this channel option has an unmet minimum-contact priority. |
| `is_priority_calendar_requirement` | Whether a configured calendar contact is due and not already satisfied. |
| `marginal_fee` | Predicted fee/revenue for the channel option, including any explicit SQL adjustment. |
| `marginal_cost` | Estimated cost of this contact option. |
| `marginal_n` | Contact-count contribution of the option; 1 per dialer candidate. |
| `marginal_profit` | Predicted fee minus estimated contact cost. |
| `marginal_margin` | Marginal profit divided by marginal fee. |
| `rank_profit` | Candidate rank based on profit and priority ordering; lower is better. |
| `rank_margin` | Candidate rank based on margin and priority ordering; lower is better. |
| `rank_weighted` | Combined/assigned selection rank after the procedure's priority rules; lower is better. |
| `is_proposed_contact` | 1 when the candidate was selected as a contact recommendation; 0 otherwise. |
| `is_fasttrack` | Whether the row comes from the explicit fast-track request branch. |
| `upload_date` | Date the recommendation or segment is intended to appear in the operational export. |
| `phone` | Candidate or selected telephone number, depending on the output. |
| `phone_field` | Source field associated with the selected dialer phone. |
| `phone_pkt_member` | Packet member associated with the selected dialer phone. |
| `priority` | Dialer order assigned from a randomized sorter biased by time zone; lower numbers are earlier. |
